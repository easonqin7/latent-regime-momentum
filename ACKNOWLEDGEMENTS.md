# Acknowledgements and lineage

The initial research direction was inspired by Aymen Hafsaoui's [portfolio-optimization-regime-switching](https://github.com/aymen-hafsaoui/portfolio-optimization-regime-switching) project. This repository documents a subsequent stock-momentum and Student-t HMM allocation study from the author's supplied notebook. It does not reproduce the upstream project's reported results, GARCH model, constrained optimization or asset universe.

The supplied notebook is the source of the numerical implementation and saved baseline outputs. AI assistance was used during code review, research iteration, documentation and repository packaging. The project presents inspectable methods and limitations rather than claiming an independently certified or entirely unaided implementation.

Hamilton's regime-switching framework and Student-t latent-variable estimation provide the methodological background. Financial-performance claims are supported only by the explicitly identified local research evidence, not by the cited literature.

No upstream repository code was imported during this publication pass. No blanket open-source license is assigned here: code lineage and third-party data rights should be confirmed before broader redistribution or relicensing. Public visibility alone is not a grant of additional reuse rights.
